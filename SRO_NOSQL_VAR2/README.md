Мини-проект по дисциплине «Проектирование и применение NoSQL-технологий». 
**Вариант 2:** Разработка NoSQL-подсистемы для учета студентов, дисциплин и их успеваемости на базе документоориентированной СУБД MongoDB.

## 🛠 Стек технологий
*   **Язык:** Python 3.10+
*   **База данных:** MongoDB 7.x
*   **Библиотеки:** PyMongo, python-dotenv, pytest

## 📂 Структура проекта
*   `src/` — исходный код (подключение к БД, запросы, демо-скрипт)
*   `scripts/` — скрипт генерации и заполнения базы данных (`seed.py`)
*   `tests/` — автотесты (pytest)
*   `docs/` — отчет, презентация и схема архитектуры
*   `.env.example` — пример файла конфигурации (без секретов)
