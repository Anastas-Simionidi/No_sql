## 📌 Описание проекта
В данной лабораторной работе исследуется стратегия горизонтального масштабирования (шардирования) документного хранилища на примере симуляции выдачи книг в библиотеке.

Цель — оценить эффективность трех разных видов Shard Key по кардинальности, частоте и монотонности при двух типах нагрузки (равномерная и с перекосом).

### Моделируемые Shard Key:
1. `genre_low_card` — низкокардинальный ключ по жанрам (`genre_id`).
2. `hashed_reader` — высококардинальный ключ читателя с хешированием (`reader_id`).
3. `range_event` — диапазонный ключ по монотонно растущему ID события (`event_id`).

### Объем данных в симуляции:
* **Документов (N):** 12 000
* **Запросов (Q):** 30 000
* **Количество шардов:** 3
